# 🛒 TheLook E-commerce Dashboard

## Overview

This project is an interactive E-commerce Dashboard built using Microsoft Excel to analyze sales, customer behavior, inventory, and product performance using the TheLook E-commerce Dataset.

## Tools

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Pivot Tables
- Data Modeling

## Features

- Executive Dashboard
- Sales Analysis
- Customer Analysis
- Product & Inventory Analysis
- Customer Journey Funnel
- Forecasting
- Interactive Slicers
- KPIs

## KPIs

- Total Orders
- Total Sales
- Return Rate
- Completed Orders
- Processing Orders
- Inventory Cost
- Product Profit
- Website Traffic
- Visitors
- Sessions

## Business Problem

The analysis focuses on identifying the reasons behind high Cart Abandonment and increasing Product Return Rates.
