# 📖 Overview

This project presents a complete **E-commerce Analytics Dashboard** built using **Microsoft Excel**.

The dashboard analyzes customer behavior, sales performance, inventory, and product performance using **TheLook E-commerce Dataset**, transforming raw data into meaningful business insights.

The project follows the complete Data Analytics workflow:

- Data Cleaning
- ETL Process
- Data Modeling
- DAX Measures
- KPI Development
- Dashboard Design
- Business Insights
- Forecasting

---

# 🎯 Business Problem

The business aims to identify the causes of:

- 🛒 High Cart Abandonment
- 🔄 Increasing Product Return Rates

The dashboard provides insights that help improve customer experience and support data-driven business decisions.
